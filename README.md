# Afet Kahramanları – Güvenkent

5. sınıf öğrencileri için geliştirilen 2.5D afet farkındalığı macera oyunu.

## Başlangıç
```bash
npm install
npm run dev
```

## İlk sürüm
- React + TypeScript + Vite ve Phaser altyapısı
- Öğrenci giriş taslağı (henüz kimlik doğrulaması ve kalıcı puan yok)
- Öğretmen sistemi için bilgilendirme ekranı (gerçek giriş henüz yok)
- Beş bağımsız ses/yazı tercihi (gerçek ses varlıkları sonraki aşamada)
- Phaser teknik test sahnesi (nihai şehir görseli **değildir**)

## Tasarım standardı
Boş geometrik şekiller nihai Güvenkent haritası gibi sunulmaz. Önce yeni şehir ve karakter varlıkları onaylanacak, sonra sahneler geliştirilecektir.
