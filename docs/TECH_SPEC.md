# Teknik Mimari

React, TypeScript, Vite, Phaser. Daha sonra Supabase ve Vercel.

- React: giriş/ayarlar/öğretmen paneli.
- Phaser: harita, animasyon, karakterler, etkileşimler.
- Ses tercihi: voice/text/ambience/music/effects; ayrıca reducedMotion.
- Merkezi puan sistemi henüz entegre değildir; kullanıcıya sahte puan/oturum başarısı gösterilmez.
- Geliştirme sırası: kaliteli görsel varlıklar -> ilk oynanabilir şehir/okul dilimi -> diğer afetler -> veri tabanı -> final -> test ve yayın.
